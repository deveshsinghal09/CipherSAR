# Contributing

1. Create a focused branch from `main`.
2. Keep commits small and use imperative messages such as `Add layering detector tests`.
3. Run `npm run typecheck`, `npm test`, and `npm run build`.
4. Open a pull request with the problem, approach, screenshots or API examples, and test evidence.
5. Do not include real financial/customer data, credentials, generated build output, or personal secrets.

By contributing, you agree that your work may be distributed under the MIT License.
