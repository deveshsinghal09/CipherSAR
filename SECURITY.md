# Security policy

CipherSAR is a demonstration and is not approved for production financial data.

Do not report vulnerabilities through a public issue if they include exploit details or sensitive information. Contact the repository owner privately through GitHub.

Never commit:

- customer or transaction data from a real institution;
- credentials, tokens, connection strings, or private keys;
- exported investigation evidence containing sensitive data.

Production use requires identity and access management, encryption, audit logging, secure secrets storage, dependency monitoring, data retention controls, and an independent security review.
